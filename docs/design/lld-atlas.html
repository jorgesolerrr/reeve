View 4 Workspaces — git seam · WorkspaceProvider

From 07-lld-workspaces.md (#14). Nothing is stored that git cannot re-derive: existence is git worktree list, base and provenance are git config on the branch. Two laws govern every deletion — never delete what you can't prove you created (the reeve-created marker gates branch deletion) and the managed root is its own proof (directories under ~/.reeve/worktrees/ may be force-deleted; outside it, nothing, ever).

coreworkspaces · review · domain

services/reviewmerge: clean worktree + base checked out in main → git merge no flags → conflict = abort + error → done on landing → destroy tail; cleanup failure after landed merge = warning. push: -u origin, keeps branch, back to Backlog
domain/workspace_locksper-ticket async mutex map — create/destroy/merge/push serialize; sequencing is domain law, so the lock lives in core
domain/board_derivationdiff non-empty ⟺ ahead_count(base…HEAD) > 0 ∨ dirty/untracked · derived per query, no cache · 1 × worktree-list + 2 reads per live workspace
seams/{git, workspace}Git: typed domain ops, parsed values, GitError — the core never sees argv or porcelain. WorkspaceProvider: create · probe · destroy(disposition) · spawn_spec → CommandSpec — the container seam, PTY-shaped

View 5 Runs — run registry · pty

From 08-lld-runs.md (#15). Liveness lives only in the in-memory registry — no status column, nothing on disk to lie (derive-don't-store applied to processes). One exit path: the main process's death is the domain event, and nothing a Run spawned survives it — the group dies with the Run. Logs are files from day one, written before the UI sees the bytes.

coreruns service · seams
services/runsthe seven operations (incl. read_run_log, amended into 03) · registry: Mutex<HashMap<(project, ticket), RunEntry>> — one global lock, never held across await · Starting reservation makes sequentiality atomic: any entry ⇒ run_active
seams/ptyPty::spawn(spec, size, log_path, sink, on_exit) · RunHandle: write_stdin · resize · kill (hard group kill, idempotent) · sink is pre-scoped and direct-call — the hot path skips 06's channel pattern on purpose (pty_output is 03's declared exception)
seams/run_historyinsert · finalize · mark-interrupted · list · log lookup — over the run tables in 06's index.sqlite
start_run choreographyreserve → resolve (agent: regen AGENTS.md temp+rename · terminal: powershell.exe / $SHELL · verify: Verify Command) → create log → spawn 80×24 → insert row → swap to Live. Unwind on failure: no row — failed starts are not Runs
↑infra implements both seams
infrapty · index
ptyportable-pty, argv never a shell · one reader thread per Run: read 8 KiB → append raw bytes to log (flush per chunk) → incremental UTF-8 (carry buffer at chunk edges) → emit. Per-chunk, no coalescing — the kernel buffer self-limits the rate; extension point documented
process groupsUnix: setsid ⇒ pgid = child pid, kill = kill(-pgid) · Windows: Job Object per Run, KILL_ON_JOB_CLOSE — assign after spawn, kill = TerminateJobObject, and the OS reaps the tree free if reeve crashes (Tier 1 gets the hard guarantee)

View 6 Sources — TicketSource · gh_client · materialized regions

From 09-lld-sources.md (#16). The seam cut: the trait is pure remote I/O — materialization (id allocation, region rendering, file writes) is service code, written once for every strategy (emdash's 12-provider lesson). Manual is absence, not a strategy: no type implements the trait for it; a manual ticket is just a Ticket without a source reference. The local file is truth — remote state is a datum, never an order.

View 7 Frontend — query cache · terminal registry · viewers · review

From 10-lld-frontend.md (#17). The ceiling is law: one query cache (TanStack Query) + one UI store (zustand), nothing else — no router (navigation is store state), no client mirror of server data. lib/ is the only module that talks to the backend; everything long-lived that isn't server state (terminals) lives outside the React tree. Feature-folder interiors stay prototype territory; this view is the load-bearing structure.
