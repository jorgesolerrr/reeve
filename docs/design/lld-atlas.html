Crate graphCargo.toml dependency lists make the rings physical: forbidden crates simply don't compile.

Clippy banscrates/reeve-core/clippy.toml disallows std::process::*, tokio::process, and std::fs entry points — "core does no I/O" made lintable, covering what std smuggles past the graph.
3
Ring testsrc-tauri/tests/ring_rule.rs — a plain #[test] walking the sources: fails on tauri:: outside ring 1 or rusqlite/portable_pty outside ring 3. Runs with cargo test anywhere, no CI-only script.
4
Type-contract checkgenerate_types -- --check: regenerates to temp, diffs against the committed types.ts, fails on drift. The frontend can never disagree with the Rust types silently.

View 3 Graph — vault · index · context_assembler

From 06-lld-graph.md (#13). One parse (vault) feeds one cache (index) feeds one pure algorithm (context_assembler). The SQLite file is disposable by policy: rebuild, never migrate. graph_changed has exactly one emission path — the watcher — so reeve's own writes and external edits are indistinguishable downstream.
