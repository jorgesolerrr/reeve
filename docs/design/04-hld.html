View 1 Component architecture

Three rings with a strict inward dependency rule, a React frontend above them, and the outside world below. Adjacent layers depend downward only; the boundary between frontend and Ring 1 carries exactly two channels.

View 2 Application flow — the memory loop

One unit of work, end to end. The cycle is the thesis: the graph is both the retrieval context for the next run and a deliverable of the last one — steps marked ★ are the differentiator.

States are derived, never stored — only done lives in front-matter. In Progress / In Review are recomputed from git + process state at query time; a hand-deleted worktree simply vanishes from the next query.
Everything on this page is a file — tickets, epics, notes and docs are Markdown in the repo; the SQLite index and PTY logs under ~/.reeve are derived or operational, deletable without data loss.
Offline by default — only import/refresh/close-offer and push touch the network; they fail explicitly and never block. Agents bring their own network.
